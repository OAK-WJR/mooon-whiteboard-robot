# 顶部 PCB 的 USB／电池供电模式

本表检查当前顶部原理图和固件。**无线供电软件策略已实现；完整 USB 电源管理和实板验证尚未完成**。电机、外部电池和充电器选购均不在本次范围；这里只使用顶部供电接口的条件。

## 当前实际连接

USB 的 `VBUS_RAW` 经 D1 到 `LOGIC_VIN_OR`；`VBAT_PROTECTED` 经 D2 到同一节点，U4 将它降压为 `MAIN_3V3`。CH343 的 VDD5/VBUS 接 USB，VIO 接 `MAIN_3V3`，ACT# 未连接。U3、CH343 VIO 和底板编码器 3.3V 接点共用主控电源。U5 的 VIN 直接接电池接口，其 EN 由 GPIO14 和外部下拉控制。

这些连接已从当前原生网表核对。`VBAT_PROTECTED` 是接口名称，完整输入连接器和保护尚未落实，不能把标签当成保护功能。

## 必须区分的状态

| 输入／事件 | 当前电路或固件的行为 | 完成设计所需的证据 |
| --- | --- | --- |
| 只接 USB、尚未枚举 | U4 可为主控与编码器供电；CH343 与主控分别退出复位。C6 固件等待有效电池电压，单独 USB 条件下不初始化无线 | 真实 `bMaxPower`、枚举前电流及插入浪涌；无线不能根据串口已打开就假定取电额度足够 |
| 只接 USB、已配置 | 串口可用于控制的设计意图成立，但没有 ACT# 状态输入或实际 USB 电流测量 | 完整顶板及底板接口负载下的电流、3.3V 最低值、诊断与复位可靠性；枚举不等于自动获得 500mA |
| 只接 USB、电脑挂起 | CH343 可自行挂起；其余主控和编码器供电仍在。当前程序没有接收 CH343 挂起状态 | 整个设备的挂起电流与恢复路径；不能只引用 CH343 自身的低功耗数值 |
| 只接电池 | D2/U4 供给主控；USB 芯片 VDD5/VBUS 无电、VIO 有电 | D1 回灌、UART/复位引脚状态、USB 端口电压；无线与主控电源的负载瞬态 |
| USB 和电池同时接入 | 两路由二极管按电压关系供给 U4，通常较高的电池路承担主控负载 | 两路电流方向、USB 地/供电扰动、插拔瞬态及是否触发复位 |
| 保持 USB、断开电池 | U4 输入从电池路转向 USB 路；ADC 检出电池电压越界或采样失效后，固件撤销控制并自动复位；检测与复位存在延时 | 切换期间 3.3V 波形和 USB 取电额度；同时收回不再有供电条件的运动许可 |
| 保持电池、拔出 USB | 主控应继续由电池供电；USB 芯片进入无 USB 电源状态 | EN/BOOT 不出现非预期脉冲；USB 控制租约失效并停止相关运动；后续无线接管符合既有协议 |
| 两路都断开或低压反复 | 电容放电、主控复位；两路电压采样可能存在异步掉电 | EN/BOOT、3.3V、采样脚及 ARM 的实测波形；没有误启动、锁死或采样引脚异常供电 |

WCH v2.0 §5.2、§5.4 说明 CH343 同时监测 V3/VIO 复位，其 ACT# 表示配置状态并在挂起时无效。因此，**不能用 ACT# 先打开它自己的 VIO**：VIO 尚未供电时芯片就无法正常完成配置。ACT# 也不包含 `bMaxPower` 所声明的电流数值。[WCH 原厂手册](https://files.waveshare.com/wiki/ESP32-S3-LCD-1.3/CH343DS1_EN.pdf)。

USB-IF 的更新将挂起电流限值列为 2.5mA；插入浪涌测试还需要规定的采样和电流积分，不能只检查一个电容的标称值。这些属于**整台 USB 设备**的要求，不能把 ESP32 或编码器的耗电漏掉。[USB-IF 电气一致性更新](https://compliance.usb.org/index.asp?UpdateFile=Electrical)。

## 软件修正和剩余硬件条件

C6 的启动流程现在先提供 UART0 与 ADC，在连续有效电池读数满足条件后才调用 `transport.begin(...)`。读数失效或供电越界会先撤销控制，再请求软件复位；下一次启动重新判断供电。RTC 标记可在软件复位后通过 USB 读取。具体阈值、启动阻塞、失败行为及证据见[无线供电策略](WIRELESS_POWER.md)。

当前 ACT# 仍未连接，程序没有真实 USB 配置和挂起状态。无线策略不能证明剩余 MCU、编码器和桥接器负载满足枚举前或挂起电流；自动复位的检测和执行延时也不能代替插拔浪涌测量。电池供电时的 Wi-Fi/BLE 和 USB 自动恢复均保留，实际链路和电流仍需测试。

本次无线软件更新没有改变供电电路或打开运动。当前 CH343G 描述符、输入保护和电源切换方案仍需定案；板上新增器件也必须计入五片顶部成品成本。
